Appendix S3: notes for the datasetThe empty cells represent missing information								Below are the ecological variables for all headings								CRU data represents climate research unit data (http://www.cru.uea.ac.uk/data)								NCEP data represents climate data (NCEP/DOE AMIP-II Reanalysis (Reanalysis-2) Model)								IGBP data represents IGBP data (https://daac.ornl.gov/SOILS/guides/igbp.html)								HWSD data represents harmonized world soil database (http://webarchive.iiasa.ac.at/Research/LUC/External-World-soil-database/HTML/)								Xu data sets represent global soil microbial biomass maps (https://daac.ornl.gov/SOILS/guides/Global_Microbial_Biomass_C_N_P.html)								Variables		Ecological meaning						"Country"		Country
